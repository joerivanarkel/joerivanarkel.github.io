## Adding a project

Copy `src/components/projects/_Template.vue`, set `meta.title` and `meta.date`, fill in the card. Projects, the sidebar TOC and the sort order update automatically. Details: [docs/adding-a-project.md](docs/adding-a-project.md). Architecture: [docs/architecture.md](docs/architecture.md).
