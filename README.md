# Portfolio

This is my portfolio. It is a work in progress.

## Adding a project

1. Copy `src/components/projects/_Template.vue` to `src/components/projects/<Name>.vue`.
2. Set `meta.date` (ISO `YYYY-MM` or `YYYY-MM-DD`) and fill in the card.
3. That's it: projects are auto-discovered and sorted newest first (optional `meta.order` breaks ties).

Language badge colours live in `src/data/languages.ts`.
